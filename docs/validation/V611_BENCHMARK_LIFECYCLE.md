# Atlas ROS v6.1.1 Benchmark Lifecycle

## Provider-free semantic

Default mode. Validates reasoning, management structure, semantic fidelity, and execution projection with zero provider writes. Evidence belongs in Review Records rather than a duplicate operational project.

## Shadow orchestration

Generates provider-neutral plans, commands, journals, and receipts with zero provider writes. It validates orchestration and reconciliation behavior without applying commands.

## Attended provider canary

Used only when provider behavior itself requires revalidation. It requires an exact object budget, explicit attended authorization, provider readback, reconciliation, and retained evidence.

## Operational separation

A version benchmark does not create a new Portfolio Project or Todoist hierarchy by default. Existing durable operational records remain the business source of truth. A dedicated Benchmark Runs collection is deferred to a separately governed v6.2 decision.
