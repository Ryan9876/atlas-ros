# Atlas ROS v6.1.1 Restoration Requirements

The exact candidate artifact must be restored independently from its packaged source distribution and wheel.

The restored runtime must verify:

- package identity `6.1.1rc1`
- Confidence Dimension V1 and Reasoning Coherence Result V1 imports
- Reasoning Coherence benchmark eligibility
- Semantic Fidelity and CloudVision invariance
- Execution Planning
- Execution Orchestration and critical fixtures
- Canonical Reconciliation
- zero provider writes
- checked-in schema readability
- candidate checksums
- v6.1.0 rollback source and wheel restoration

A successful restored candidate remains non-production until separately authorized.
