# Atlas ROS v6.1.1 Release Boundary

The v6.1.1 branch and draft pull request are development and validation surfaces only.

Prohibited without a separate exact authorization from Ryan:

- merge to `main`
- final `v6.1.1` tag
- final GitHub Release publication
- Release Index update
- System State update
- integration or Automation Register activation
- production authority change

The future authorization must identify the exact candidate commit, exact package SHA-256, and exact Full Validation record. Until then, Atlas ROS v6.1.0 remains Active and Atlas ROS v6.0.0 remains the immediate rollback.
