# Atlas ROS v6.1.1 Attended Horizon Promotion

The horizon engine is deterministic and provider-free. It proposes the next controlled-pilot state from verified evidence:

1. Scope definition
2. Ownership and low-risk targets
3. Controls and rollback
4. Separately authorized delegated execution
5. Conditional evidence review and go/no-go decision
6. Separately approved future rollout

Every proposal reports zero provider writes and requires attended authorization before a Notion or Todoist object can be created or modified. No transition is automatic, scheduled, or event-triggered.
