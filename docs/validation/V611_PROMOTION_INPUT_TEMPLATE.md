# Atlas ROS v6.1.1 Promotion Input Template

After exact-artifact Full Validation passes, production promotion requires a separate instruction in this form:

`Promote Atlas ROS v6.1.1 candidate <EXACT_COMMIT>, package SHA-256 <EXACT_PACKAGE_SHA256>, under <EXACT_FULL_VALIDATION_RECORD>.`

No placeholder value authorizes promotion. The exact candidate commit, package digest, and Full Validation record must be read from final candidate evidence.
