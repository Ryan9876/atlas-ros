# Atlas ROS v6.1.1 Compatibility Expectations

The candidate must preserve:

- existing Todoist project, section, priority, label, description, and hierarchy behavior
- command parsing and reconciliation semantics
- execution orchestration object counts and critical fixtures
- provider separation, idempotency, readback, and fail-closed recovery
- the exact CloudVision parent and three current checkpoints
- all historical v5.2 through v6.1 records

The v6.1.0 differential must report zero unexplained drift for existing behavior. New differences are limited to explicit confidence dimensions, coherence evidence, coherent responsibility and workstream metadata, provider-free benchmark modes, and horizon proposals.
