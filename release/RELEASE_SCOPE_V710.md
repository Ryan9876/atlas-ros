# Atlas ROS v7.1.0 Draft Release Scope

Status: Draft candidate scope. Atlas ROS v7.0.1 remains Active.

1. Complete Drive retirement readiness while keeping retirement and deletion disabled.
2. Add governed item-level historical-cleanup contracts, planning, simulation, authorization, readback, and receipts.
3. Replace release-family policy duplication with a version-neutral deterministic release compiler.
4. Isolate legacy, migration, and release code from production runtime.
5. Add verified lazy loading and an optional authenticated read-only warm runtime.
6. Preserve v7.0.1 behavior and v7.0.1/v6.5.0/v6.2.0 restoration.

No promotion, authority activation, Drive deletion, credential revocation, historical deletion, integration expansion, or autonomous consequential execution is in scope.
