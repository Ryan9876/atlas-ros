# Atlas ROS v8.2.0 Draft Release Notes

Atlas ROS v8.2.0 extends attended reconciliation so ordinary natural-language comments on governed Todoist parents and subtasks are retrieved, interpreted, and converted into reviewable management and execution plans.

## Highlights

- Composite `Reconcile ROS` and `Reconcile ROS inbox` ingress across Universal Inbox and Todoist.
- Stable Todoist comment events for parent tasks and linked subtasks.
- Backward-compatible explicit `@atlas` commands.
- Deterministic common commitment and Ryan follow-up language.
- Bounded same-comment pronoun resolution and timezone-aware relative dates.
- Transparent inferred fields with origins, evidence, confidence, and blockers.
- Separate delegate delivery and Ryan checkpoint dates.
- Exact attended authorization, readback, recovery, and replay controls.
- Existing-schema shared ledger compatibility with no production Notion migration.

No autonomous execution, unattended provider writes, or integration-scope expansion is enabled.
