# Atlas ROS v6.1.1 Release Notes

Atlas ROS v6.1.1 makes reasoning metadata and execution decisions describe one truthful governed conclusion.

## Reasoning coherence

The new Reasoning Coherence Gate validates clarification state, planning-model selection, responsibility resolution, execution eligibility, routing, confidence completeness, and user-facing explanations before management-plan approval. Material contradictions fail closed and require attended review.

## Explicit confidence dimensions

Confidence is now represented separately for intent partitioning, planning-model selection, record classification, responsibility resolution, routing, and semantic fidelity. Each dimension records its evidence basis and whether it affects execution eligibility or requires attended review.

## Controlled technology pilots

Controlled infrastructure and automation pilots resolve to governed project-delivery responsibility and the Active Projects workstream without vendor-specific exceptions. The same behavior is validated for Arista, Cisco, infrastructure monitoring, automation proofs of concept, and controlled infrastructure trials.

## Benchmark lifecycle

Provider-free semantic evaluation is the default. Shadow orchestration may generate provider-neutral evidence with zero writes. Attended provider canaries require explicit authorization, a disclosed object budget, provider readback, and reconciliation.

## Horizon promotion

A provider-free horizon engine proposes the next controlled-pilot state while requiring separate attended authorization for every provider mutation.

## Compatibility

The approved CloudVision parent and three checkpoints are unchanged. Provider permissions, autonomy, orchestration, reconciliation, calendar, messaging, email, deletion, and scheduling boundaries are unchanged.
