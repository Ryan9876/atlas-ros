# Atlas ROS v5.3.0 Release Scope

Status: Final compatibility release candidate scope; production promotion is not authorized by this document.

## Base and rollback

- Current Active authority: Atlas ROS v5.2.0.
- Immediate immutable rollback if promoted: Atlas ROS v5.2.0.
- Older recovery baseline: Atlas ROS v5.1.1 remains unchanged.

## Included scope

- Responsibility-first Classification Intelligence using `Responsibility -> Outcome -> Workstream -> Activity`.
- Separate record classification, responsibility domain, outcome, workstream, activity, operating context, and deterministic destination.
- Version 2 reasoning contract with explicit version 1 compatibility projection.
- Structured decisive evidence and concise evidence-aligned explanations.
- Manager-intent inference as an independently scored supporting signal that cannot override stronger explicit evidence.
- Governed accepted, challenged, corrected, and unresolved classification states.
- Legacy, shadow, attended, and explicit semantic routing modes.
- Safe clarification and v5.2 compatibility fallback for low-confidence or conflicting cases.
- Evaluation dataset, quantitative calibration, ADR, standards, implementation-registry reconciliation, observability, and rollback evidence.

## Production operating mode

The package preserves legacy mode as the production-compatible default. Shadow and attended modes do not change routing authority. High-confidence semantic mode requires explicit configuration and remains attended and review-first. No classification result can autonomously create provider writes or change production policy.

## Excluded scope

- Knowledge Composition Engine and Management Structure Engine roadmap completion.
- Execution Planner, task-economy, orchestration, provider-adapter, or reconciliation roadmap expansion.
- W-number interface retirement.
- New integrations, permission expansion, messaging, email, calendar, deletion, autonomous scheduling, or unattended consequential processing.

## Promotion gate

Promotion requires successful repository-native CI, release-candidate validation, checksum-bound draft publication and readback, Drive-independent restoration, Full Validation, Decision Log and Review Record reconciliation, rollback proof, and Ryan Smith's explicit production-promotion authorization.
