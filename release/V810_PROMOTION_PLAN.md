# Atlas ROS v8.1.0 Controlled Promotion Plan

Status: proposed sequence; not authorized for execution.

## Preconditions

1. Full Validation passes for one exact candidate commit.
2. The build-once artifact and every package and evidence digest are retained.
3. The migration assessment confirms zero production schema changes.
4. The immediate rollback release and restoration evidence are verified from live authority.
5. A Governing Decision and Acceptance Review bind the exact package.
6. Ryan explicitly authorizes the exact package and complete transaction.

## Controlled sequence

1. Merge only the validated implementation and package-binding evidence.
2. Add immutable publication controls bound to the retained artifact; do not rebuild.
3. Publish immutable tag and GitHub Release `v8.1.0` only after exact authorization.
4. Independently verify the tag target, release assets, checksums, clean installations, zero-write evidence, and restoration of the then-current Active and immediate rollback releases.
5. Confirm that no Notion migration is required.
6. Activate canonical GitHub authority only after independent publication verification passes.
7. Update Notion System State to the same Active and rollback identities.
8. Perform final live readback of GitHub authority, Release Index, immutable manifest, Notion System State, Integration Inventory, rollback integrity, and preserved boundaries.

## Stop conditions

Stop before publication when any identifier or digest differs from the authorized package. Stop before authority activation when independent publication readback fails or required integrations are not ready. Stop before final completion when GitHub and Notion authority disagree.

## Exclusions

The promotion does not authorize provider data writes, Todoist tasks, messaging, email, calendar actions, scheduling, credentials, deletion, integration-scope changes, profile activation, intent-memory inference, or live-network execution.
