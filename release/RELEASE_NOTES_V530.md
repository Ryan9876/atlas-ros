# Atlas ROS v5.3.0 — Classification Intelligence

Status: Final release-candidate notes. Production promotion remains separately authorized by Ryan Smith.

## Added

- Responsibility-first classification across People Leadership, Project Delivery, Operational Stewardship, External Dependency, and Capability Building.
- Version 2 reasoning contracts with structured decisive evidence, workstream, operating context, challenge state, fallback reason, and explicit version 1 projection.
- Concise evidence-aligned explanations that disclose material ambiguity without exposing unnecessary internal reasoning.
- Manager-intent inference as a confidence-scored supporting signal that cannot override stronger explicit ownership, authority, safety, decision, risk, project, or operational evidence.
- Governed accepted, challenged, corrected, and unresolved classification states.
- Legacy, shadow, attended, and explicit semantic routing modes.
- A versioned 30-case Classification Intelligence evaluation set and deterministic quantitative evaluator.
- ADR-005, the Classification Intelligence operating standard, governed configuration, observability, implementation-registry reconciliation, and release evidence.

## Preserved

- Deterministic Record Routing Service authority.
- Provider separation and classification-free provider adapters.
- Existing Todoist formatting, section routing, hierarchy, duplicate prevention, readback, and reconciliation contracts.
- Attended and review-first execution.
- Safe clarification and Atlas ROS v5.2.0 compatibility fallback.
- Ryan-only production-promotion authority.

## Production rollout

The package preserves legacy mode as the production-compatible default. Shadow and attended modes provide evidence without changing routing authority. High-confidence semantic mode requires explicit governed configuration and remains attended. No Classification Intelligence metric or result may autonomously create a provider write or change production policy.

## Rollback

If promoted, Atlas ROS v5.2.0 becomes the immediate immutable rollback. Atlas ROS v5.1.1 remains an older immutable recovery baseline.
