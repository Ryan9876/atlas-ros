# Atlas ROS v6.0.0rc1 Release Notes

This major candidate completes the approved Atlas ROS roadmap. Semantic capabilities are now the
sole runtime architecture. Reconciliation is governed by explicit field authority, deterministic
plans, structured conflicts, stable idempotency, safe checkpoints, exact attended authorization,
provider readback, and fail-closed receipts.

The numbered workflow modules and legacy facade package are intentionally absent. See the v6
canonical cutover, breaking changes, and rollback guides before upgrading custom integrations.

Atlas ROS v5.6.0 remains Active and is the exact prospective immediate rollback. This candidate is
not production and requires Ryan’s explicit promotion decision.
