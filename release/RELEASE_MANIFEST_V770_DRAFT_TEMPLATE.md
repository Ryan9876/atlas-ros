# Atlas ROS v7.7.0 Draft Immutable Release Manifest Template

Status: candidate template only. Generated exact identities and digests from the frozen validation workflow control the authorization checkpoint.

## Required exact-package fields

- Exact source commit
- Retained artifact ID and outer digest
- Source distribution and wheel SHA-256
- SPDX SBOM and source-manifest SHA-256
- Validation-receipt and zero-provider-write receipt SHA-256
- Initialization circuit-breaker evidence SHA-256
- Draft immutable-manifest SHA-256
- Active predecessor and rollback identities
- Cold and warm external-read counts
- Terminal-lock proof and post-terminal provider-call count
- Workflow run ID and elapsed time
- Build count of one

## Preserved boundaries

Publication, tag creation or movement, merge, canonical authority activation, Notion System State changes, schema changes, Todoist writes, messages, calendar actions, schedules, credentials, integration-scope changes, deletion, profile activation, intent-memory execution, and live-network actions remain unauthorized until a separate exact-package decision.
